# Deloitte Data Analytics Job Simulation

## About this project

Completed the Deloitte Australia Data Analytics Job Simulation through [Forage](https://www.theforage.com/simulations/deloitte-au/data-analytics-s5zy).

This virtual job simulation provided practical experience in data analytics and forensic technology through business scenarios involving Daikibo Industrials, a fictional manufacturing company.

The project involved analysing factory machine telemetry data, building an interactive Tableau dashboard, and investigating employee equality scores using Microsoft Excel.

## Tasks completed

### Task 1: Data Analysis – Factory Telemetry Dashboard

- Analysed machine telemetry data collected from four manufacturing factories.
- Imported and explored JSON telemetry data using Tableau.
- Created calculated fields to identify unhealthy machine signals.
- Built visualizations to compare machine downtime across factories.
- Analysed downtime by machine type.
- Developed a dashboard to help identify operational inefficiencies and potential maintenance priorities.

**Deliverable:** Tableau dashboard and packaged workbook.

### Task 2: Forensic Technology – Employee Equality Analysis

- Analysed employee equality scores across different factories and job roles.
- Used Microsoft Excel to classify equality scores.
- Applied conditional logic and nested IF formulas.
- Categorized equality scores into three classifications:
  - Fair
  - Unfair
  - Highly Discriminative
- Explored potential pay-equity concerns through data classification.

**Classification formula:**

`=IF(ABS(C2)>20,"Highly Discriminative",IF(ABS(C2)>10,"Unfair","Fair"))`

**Deliverable:** Completed Excel equality analysis workbook.
